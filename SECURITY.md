# Security Policy

## Supported versions

The default branch of this template receives security maintenance. Repositories created from the template have an
independent history and must replace this section with their own supported-version policy.

| Version                  | Supported |
| ------------------------ | --------- |
| Default branch           | Yes       |
| Older template snapshots | No        |

## Report a vulnerability

Do not open a public issue for a suspected vulnerability.

Use **Security > Report a vulnerability** in the affected repository when private vulnerability reporting is enabled.
Otherwise, email [bayudwiyansatria@gmail.com](mailto:bayudwiyansatria@gmail.com) with:

- the affected repository, version, branch, or commit;
- impact and the conditions required to reproduce it;
- minimal reproduction steps or a proof of concept;
- relevant logs with secrets and personal data removed; and
- whether the issue is already public or under active exploitation.

Maintainers will acknowledge the report, investigate it privately, and coordinate remediation and disclosure with the
reporter. Generated repositories own their response process; this template does not automatically update them.
