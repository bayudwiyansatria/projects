# Support

Use the repository's issue forms for reproducible bugs and feature proposals. For setup questions about this template,
first review the [README](README.md) and [template guide](docs/README.md), then email
[bayudwiyansatria@gmail.com](mailto:bayudwiyansatria@gmail.com) if the answer is not documented.

Do not include credentials, access tokens, private infrastructure details, or vulnerability reports in public issues.
Report security concerns through the process in [SECURITY.md](SECURITY.md).
